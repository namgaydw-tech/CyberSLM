## Privacy and academic-integrity checks

- [ ] No `.env`, token, credential, private key, or service-account file is staged.
- [ ] No raw THEIA data, private report text, event UUID dump, production Parquet, or private
      checkpoint is committed to GitHub.
- [ ] A Hugging Face dataset upload contains only release-authorized records.
- [ ] A public demo dataset is clearly distinguished from the restricted training corpus.
- [ ] The five-step smoke checkpoint is never described as a substantively trained model.
- [ ] Deterministic answers are never presented as CyberSLM neural generations.
- [ ] Anomaly scores are described as review signals, not confirmed attacks.
- [ ] Phase 3 next-byte loss is not compared directly with Phase 4F exact-match accuracy.
- [ ] Current cross-scenario data is identified as development-exposed, not a pristine final test.

Do not fill in actual model outputs until they have been generated by the selected trained
checkpoint or registered Ollama model.

   Question: Which event type is most frequent?

   Actual Ollama output: `and 1 repeated edge occurrences.` (incorrect)
